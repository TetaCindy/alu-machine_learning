# Advanced Linear Algebra

Matrix functions written without external libraries (except task 5).

## Files

* `0-determinant.py` - `determinant` of a matrix
* `1-minor.py` - `minor` matrix
* `2-cofactor.py` - `cofactor` matrix
* `3-adjugate.py` - `adjugate` matrix
* `4-inverse.py` - `inverse` of a matrix
* `5-definiteness.py` - `definiteness` of a matrix (uses numpy)

## Requirements

* Python 3
* Code style checked with pycodestyle
