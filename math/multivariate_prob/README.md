# Multivariate Probability

Functions and classes for multivariate distributions.

## Files

* `0-mean_cov.py` - `mean_cov` mean and covariance of a data set
* `1-correlation.py` - `correlation` correlation matrix from a covariance matrix
* `multinormal.py` - `MultiNormal` class (constructor and pdf)

## Requirements

* Python 3 and numpy
* `numpy.cov` is not allowed
* Code style checked with pycodestyle
