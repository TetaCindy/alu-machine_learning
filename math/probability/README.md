# Probability

Python classes that represent probability distributions.

## Files

* `poisson.py` - `Poisson` class (constructor, pmf, cdf)
* `exponential.py` - `Exponential` class (constructor, pdf, cdf)
* `normal.py` - `Normal` class (constructor, z_score, x_value, pdf, cdf)
* `binomial.py` - `Binomial` class (constructor, pmf, cdf)

## Requirements

* Python 3
* No module imports allowed in the class files
* Code style checked with pycodestyle
